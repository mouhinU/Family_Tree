常见问题

你可能想知道

关于创建家族、加入家族与资料隐私的常见说明。

没有家族，可以自己创建吗？

可以。注册后可创建自己的家族，并邀请家人加入。

如何加入已有的家族？

在首页输入家族邀请码，或让家族管理员提供邀请链接。

必须使用电脑吗？

页面同时适配电脑和手机，可随时查看与维护家族资料。

首页会公开我的族谱吗？

不会。首页仅展示产品介绍，真实家族资料需要登录并具备相应权限后才能查看。
